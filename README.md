# Mumin OS downloads

This public repository is used only for finished Mumin OS binaries, checksums,
and download instructions.

The complete Mumin OS source code is stored separately in a private repository
and is not published here.

## Download

Open **Releases**, choose the newest Mumin OS release, and download files under
**Assets**.

GitHub automatically adds **Source code (zip)** and **Source code (tar.gz)** to
every release. Those automatic archives contain only this small public release
repository and do **not** contain the private Mumin OS source code.

When an ISO is split because of GitHub's file-size limit, download every `.part-*`
file plus `REJOIN_MUMIN_OS.cmd`, place them together in one folder, and run the
rejoin script.
